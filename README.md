# imarsen

Лендинг сервиса AI-анализа внешности.

## Стек

- HTML + Tailwind CSS (Play CDN)
- Vanilla JS (мобильное меню, FAQ-аккордеон, smooth-scroll)
- Lucide icons (CDN)

Без сборки — открой `index.html` в браузере или подними любой статический сервер:

```bash
python3 -m http.server 8000
```

## Структура

- `index.html` — все секции (hero / features / pricing / FAQ / footer)
- `assets/styles.css` — кастом-стили (glassmorphism, aurora-фон, анимации)
- `assets/app.js` — интерактив
